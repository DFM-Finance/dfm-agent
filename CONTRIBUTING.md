# Contributing

This repository is a **read-only mirror**. It is published automatically from DFM's private monorepo every time `@dfm-fi/agent` is released, and each sync replaces the whole tree, so a commit made here would be overwritten.

- **Bugs and ideas:** open an issue here. They are read.
- **Code changes:** open a pull request to show the change. We port it into the monorepo by hand, credit you in the commit, and close the PR once the next sync contains it.
- **Security problems:** see [SECURITY.md](SECURITY.md). Please don't open a public issue.
